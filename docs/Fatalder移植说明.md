# Fatalder → Cubeloom 优点移植说明（SnowLuma 版）

> 说明：本文是上游作者记录的搬迁笔记，其中「用户中心 / 插件市场 / 支付」等条目属于
> 上游商业化版本，**Cubeloom 社区版不包含**。保留原文仅为记录技术差异。

> Fatalder 面向网易版（进服机器人），Cubeloom 面向基岩版（WS/结构导入）。
> 本轮把 Fatalder 做得好的地方搬到 Qiuper 的管理端，并把 UI 换成 SnowLuma 风格。
> 日期：2026-11-01

## 一、本轮已移植（可直接用）

### 1. 多套进服配置（Fatalder：配置管理）
- 位置：管理端左栏「进服配置 · 多套房间」
- 能力：保存 / 切换 / 删除多套配置（模式、房间号、密码、备注）
- 「使用」会把连接参数复制到剪贴板，并高亮当前配置
- 存储：浏览器 localStorage（`cq-profiles-v1`），不上传服务器

### 2. 任务队列（Fatalder：任务系统）
- 位置：管理端左栏「任务队列 · 顺序执行」
- 支持四种任务，按顺序跑：
  | 类型 | 说明 |
  |---|---|
  | 游戏指令 | `/say hi`、`/fill …` 等原生命令 |
  | 代码 | 沙箱 JS eval（同控制台） |
  | 等待 | 秒数 |
  | 结构导入 | 导入当前已解析结构，可设 Y 偏移 |
- 单条失败标记后继续下一条；支持开始 / 停止 / 清空 / 进度统计
- 存储：localStorage（`cq-queue-v1`）；执行需保持页面打开

### 3. SnowLuma 风格 UI（整体重做）
- 深海军蓝背景 + 冷蓝主色 + 细边框卡片 + 等宽小标签
- 顶栏毛玻璃、状态胶囊、`?theme=light` 一键黑白切换
- 手机/平板自适应保持（≤1000px 单列、≤640px 紧凑）
- 文件：`admin/snowluma.css`（主题）、`admin/snowluma.js`（两个面板逻辑）

## 二、Cubeloom 已有、Fatalder 没有的能力

| 能力 | 说明 |
|---|---|
| 网页管理端 | Fatalder 是终端 TUI，Qiuper 是浏览器界面 + 手机可用 |
| 三步完整性保证 | 放置 → 逐块回读校验 → 缺失补建，Fatalder 只有验证等级 |
| 自适应发送窗口 | 按在途命令数调速、失败率超 5% 自动降速、补建轮退避 |
| 多格式导入 | .mcstructure / .litematic / .schem / .schematic / .nbt |
| 网页终端 + 日志流 | 实时日志、命令历史、沙箱执行 |
| 用户中心 / 插件市场 | 注册登录、插件上架、兑换码、支付 |
| 网易版账号体系 | 账号加密存储 + 每用户机器人脚手架 |
| 移动端适配 | 断点 1000 / 640，触摸友好控件 |

## 三、计划下一轮移植（需要改主程序，不只是界面）

1. **验证等级 0—3**（Fatalder 的四档：无 / 空气 / 相似 / 完全）→ 接入 `main.ts` 校验阶段
2. **每 N 区块验证**（Fatalder 的 `verify_interval`）→ 分区块流水线
3. **增量导入**（只补差异方块）→ 依赖回读结果做差集
4. **导出 schematic / 结构文件**（Fatalder 的导出功能）→ 世界回读 → 写文件
5. **导入速度档位**（区块组边长、速度上限）→ 暴露成设置项并写入主程序参数
6. **进服配置接入真实连接流程**（当前只保存/复制参数）
